# Rail
Современный скриптовый компилируемый язык программирования, вдохновлённый Java, TypeScript, Python и не только, предлагающий широкие возможности для парсинга, научных вычислений, быстрых сервисов и не только.

Если хочется чего-то простого как TypeScript, но быстрого как C++, это отличный выбор! Начать легко!

**Важно!** Язык находится в разработке с 8 мая и на данный момент мало что готово, но вы уже можете ознакомиться с концептами и предлагать свои идеи. 

**Документация с примерами кода и объяснениями**: [клик](docs/intro.md)

## Некоторые уникальные возможности:
[**Юниты**](docs/object-oriented/unit/intro.md) как наследники типов данных, работающие только с конкретными перегрузками. Потенциал под вычисление всего, что связано с расстоянием, размером и временем:
```rail
unit km extends int {
    public operator + (value: m) {
        return this + ((value / 1000) as int);
    }
}

unit m extends int {
    public operator / (value: int) {
        return (this / value) as m;
    }
}

const radius = 10 000 km + 1500 m; // 11 500 km
```

[**Аргументы с инструкциями к передаче**](docs/call/arguments.md#инструктированные-аргументы): Возможность, которая позволяет задавать условия передачи значений в аргументы для перегрузок шире, чем стандартное указание типа.
```rail
function isValidAge(age: int > 18): boolean {
    return true;
}
```

[**Выводимый тип возвращает значение**](docs/call/intro.md#выводимый-тип-возвращает-значение): Возможность, которая позволяет писать выводимый тип сразу в тип данных, минуя написание тела.
```rail
function isValidAge(age: int): age > 18;
```

[**Размерные массивы**](docs/iterable/collections/array.md):
```rail
const arr: int[3-5] = [1, 2, 3, 4]; //от трёх до пяти элементов
const arr: int[3+] = [1, 2, 3]; //от трёх элементов и больше
const arr: int[3-] = [1, 2, 3]; //от трёх элементов и меньше
const arr: int[5] = [1, 2, 3, 4, 5]; //стандартный массив на пять элементов
const arr: int[] = [i for (let i = 0; i < 10; i++)]; //массив с неограниченным количеством элементов
```
В предыдущем примере мы заметили что-то необычное внутри массива, кажется, это [**списковые включения**](docs/iterable/collections/array.md#списковые-включения).

Это лишь некоторые из особенностей, остальные вы можете узнать в документации.
