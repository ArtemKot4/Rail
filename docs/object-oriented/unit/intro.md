# Юниты
Юниты - это особенность языка Rail, направленная на серьёзное упрощение работы с данными.

Могут использоваться для научных вычислений, рассчёта графики, физики и многого другого.

Юнит - это аналог класса, но наследующий какой-либо примитивный тип данных.

После присвоения юнита, значение сможет взаимодействовать только с другим таким же юнитом, если другого не предполагают перегрузки операторов.

## Синтаксис
Чтобы создать юнит, нужно использовать ключевое слово `unit`.

```rail
unit название extends тип {}
```

Юниты точно так же могут переопределять своё поведение с другими типами данных, как и классы.

Давайте создадим километры и метры:
```rail
unit km extends int {
    public operator + (value: m) {
        return this + ((value / 1000) as int);
    }
}

unit m extends int {
    public operator / (value: int) {
        return (this / value) as m;
    }
}

```

Давайте рассчитаем радиус:

```rail
const radius = 10 000 km + 1500 m // 11 500 km
```

Попробуем сложить несовместимые юниты:
```rail
unit kg extends int {}

const weight = 100 kg;
const check = radius + weight;  // Ошибка: km нельзя сложить с kg
```
