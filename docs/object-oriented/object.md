# Объекты как самостоятельные единицы

Объекты - не обычная вещь для низкоуровневых языков, если созданы без какого-то шаблона, будь это класс, структура или trait.
Объект - это контейнер, который хранит значения за подписями: <u>ключами</u>, прям как переменные!

## Синтаксис
Объекты записываются при помощи фигурных скобок `{}`.

Значения в ключах при создании объекта записываются через `{ название_ключа: значение }`.

## Разбираемся с ключами и значениями

Если представить объект как ящик, то ключи - это подписанные полки, а значения - содержимое этих полок.

### Создаём объект

Создадим объект `animals`.

```rail
const animals = { wolf: "волк", dog: "пёс" }
```

В нём 2 ключа: `wolf` и `dog`, и каждый хранит своё значение, указанное за двоеточием.

Чтобы получить значение ключа, нужно написать `название_объекта.название_ключа` либо `название_объекта[название_ключа_как_строка]`, после чего эта запись станет значением из ключа, если он есть. 

Если же ключа нет, вы получите ошибку.

### Выводим значения ключей

Через обращение к ключам получим значения и выведем их в консоль.

```rail
console.log(animals.wolf); // волк
console.log(animals.dog); // пёс

// пробуем вывести кота
console.log(animals.cat); // ошибка! ключа "cat" нет
```

### Безопасное получение значения ключа

Для обращения к ключу мы используем `.`, но только если точно знаем, что этот ключ существует. 

В ином случае нам не всегда нужна ошибка - иногда достаточно `null`-значения. Для таких случаев была придумана другая запись обращения к ключу за значением, а именно: `?.`.

Таким образом мы спрашиваем: "Ключ есть?", и если его нет, получаем "нет" в виде `null` значения.

```rail
console.log(animals?.cat); // null
```

### Изменение значения ключа
Объекты хранят значения за ключами, но эти же ключи и отпирают доступ к ним. Таким образом мы можем обращаться к значениям и менять их.

Запись выглядит так: `объект.название_ключа = новое_значение_подходящего_типа_данных`.

Давайте поменяем "пёс" на конкретную породу.

```rail
console.log(animals.dog = "алабай"); // алабай

// или разложим на более простые выражения

animals.dog = "алабай";

console.log(animals.dog); // алабай
```

### Добавляем ключ, которого ранее не было
Обычные объекты позволяют добавлять ключи любого типа данных.

Из-за этого памяти под них выделяется больше, но мы получаем возможность использования объектов как дополняемых словарей, что позволяет в ряде случаев отказаться от строгих [`Map`](/iterable/collections/map.md) и массивов.

Добавим `cat`, которого не было.

```rail
animals.cat = "Лео";

console.log(animals.cat); // Лео. Заметьте, больше нам не нужно применять ?.
```

### const-ключи
Это ключи, значения которых изменить нельзя.

```rail
const rail = { const "author": "Artem" }

rail.author = "Ivan"; // Ошибка!
```

Добавлять извне такие ключи нельзя.

### Удаление ключей
Ключи можно удалить при помощи оператора `delete`. В таком случае обратиться к ним без оператора `?.` будет нельзя. [const-ключи](#const-ключи) удалить не получится.

```rail
delete animals.cat;

console.log(animals.cat); // Ошибка!
```

## Статические объекты
В таких объектах по-прежнему можно менять значения ключей, но новые добавить нельзя, это вызовет ошибку, и оператор `?.` с ними неприменим. В большинстве сценариев вам понадобится именно этот тип объектов, он работает быстрее, занимает меньше памяти и более предпочтителен.

Записываются как `static {}`

```rail
const quote = static { "JSON Stathem": "JSON - лучший язык!" }

quote["JSON Stathem"] = "Интересный факт, Rail реализует JSON!";

console.log(quote["JSON Stathem"]); // Интересный факт, Rail реализует JSON!

quote["record"] = "record'ы как data-классы, но лучше!"; // Ошибка
```

## Перебираем объекты
Объекты имеют собственные итератор, поэтому могут быть перебраны.

Всегда используйте оператор `&` для переменных в циклах `for of`, это позволит избежать полного копирования значений.

### `for in`
Давайте напишем цикл, который выведет все ключи. Для того, чтобы в переменную был положен ключ, нужно использовать `in`.

```rail
for(const key in animals) {
    console.log(key);
}
// wolf
// dog
```

### `for of`
`for of` позволит нам значениям быть положенными в переменную.

```rail
for(const value& of animals) {
    console.log(value);
}
// волк
// алабай
```

### Комбинируем
Мы можем применить `for i` и `for of` в одном цикле для получения ключей и значений.

Давайте рассмотрим простой пример

```rail
for(const index in animals, const value&? of animals) {
    console.log(index, value);
}
// wolf волк
// dog алабай
```

Почему `value&?`? Чтобы мы не взяли ссылку на null. Компилятор потребует вставки `?`, если не гарантированно, что количество ключей одинаково.

## Слияние объектов
Бывают случаи, когда нам нужно совместить несколько объектов, чтобы получить новый объект, где будут поля и методы каждого.

Конечно, мы могли бы сделать так:

```
const obj1 = { user1: "1", user2: "2" }
const obj2 = { user3: "3"}

for(const key of obj2, const value& of obj2) {
    obj1[key] = value;
}
```

И получили бы:

```
console.log(obj1); // { user1: "1", user2: "2", user3: "3" }
```

Но в Rail есть более простое решение. Объекты можно совмещать точно так же, как и их типы при помощи `&`.

```rail
console.log(obj1 & obj2); // { user1: "1", user2: "2", user3: "3" }
```

В первый объект добавятся ключи со значениями из второго. Если в первом уже есть ключ с таким названием, он заменится.

Вложенные объекты будут полностью скопированы, так как Rail всегда совершает полноценное копирование.
