# Знакомимся с потоками
В данной серии статей мы познакомимся с потоками в языке Rail.

Представьте, что у вас есть несколько задач, которые нельзя заставлять ждать, и нужно выполнить их параллельно. Например вы пишете одиночную игру, и одновременно должна и вычисляться игровая логика, связанная с миром, и клиентское отображение, чтобы эти процессы не зависели друг от друга и один не тормозил другой.

В таком случае нам нужно добиться результата, когда код работает независимо друг от друга.
Для этого и нужны потоки.

Язык Rail с самого начала проектировался под удобную систему потоков, чтобы это было максимально легко для любого: полного новичка, среднего уровня или опытного программиста.

## Разбираем отличия:
### Java
```java
//создание
class MyRunnable implements Runnable {
    public void run() {
        System.out.println("Thread in java");
        sleep(50);
    }
}

public class Main {
    public static void main(String args) {
        MyRunnable myRunnable = new MyRunnable();
        Thread thread = new Thread(myRunnable);
        thread.start(); //запуск
    }
}
```
## Rail
```rail
//создание
thread myThread() {
    console.log("Thread in rail);
    sleep(50);
} 

myThread(); //запуск
```
