# Цикл for of

Цикл for of позволяет перебирать значения коллекций, в которых индексы представлены только числами. Часто это [массивы](../iterable/collections/array.md) и [кортежи](../iterable/collections/tuple.md).

Синтаксис: `for(переменная of коллекция)`.

```rail
const array = [1, 2, 3];

for(const value& of array) {
    console.log(value);
}
//1
//2
//3
```

Так же работает и если нам нужно получить значения ключей объекта.

```rail
const obj = { a: 1, b: 2, c: 3 };

for(const value& of obj) {
    console.log(value);
}
//1
//2
//3
```

## Почему ссылки - это хорошо?
Вы заметили, что мы писали `&` после названия переменной в цикле. Это не просто так. По-умолчанию Rail копирует все значения, что может быть тяжёлым в случае копирования больших данных, поэтому мы можем просто ссылаться на них.

В таком случае изменение значения переменной изменит и значение внутри перебираемой коллекции. Чаще всего вам будет достаточно `const переменная&` для большинства вещей, поэтому если копирование не предусмотрено, используйте этот синтаксис.
