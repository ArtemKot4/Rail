# Цикл for in
Цикл for in позволяет перебирать индексы коллекций:

Синтаксис: `for(переменные in коллекция)`.

1.
    Массив:
    ```rail
    for(let i in [1, 2, 3]) {
        console.log(i);
    }
    //0
    //1
    //2
    ```
2.  
    Объект:
    ```rail
    for(let i in { a: 1, b: 2, c: 3 }) {
        console.log(i);
    }
    //a
    //b
    //c
    ```

**Важно!** Поскольку мы получаем индексы, по ним мы часто можем получить и значения:
```rail
const obj = { a: 1, b: 2, c: 3 };
for(let i in obj) {
    console.log(i, obj[i]);
}
//a 1
//b 2
//c 3
```
