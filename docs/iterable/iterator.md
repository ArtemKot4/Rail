## Итераторы
Итератор - механизм, благодаря которому работают переборы коллекций в циклах. 

Язык Rail позволяет создавать свои итераторы и использовать их в переборах.

## Синтаксис
Для создания итератора мы используем ключевое слово `iterator` вместо `function*` из JavaScript.
```rail
iterator название(аргументы): возвращаемый_тип_данных { 
    //тело итератора
}
```

## Аналог return - yield
Итераторы похожи на функции, однако механизм возврата значения другой.

`yield` - ключевое слово, которое позволяет возвращать значение из итератора. Сколько раз в итераторе оно было вызвано, столько раз он выдает значение. Таким образом массивы выдают значения столько раз, сколько у них длина (length).
```rail
iterator название(аргументы): возвращаемый_тип_данных { 
    yield значение;
}
```

## Пишем свой итератор
Напишем итератор, который будет представлять из себя обратный отсчёт.

```rail
iterator countdown(start: int): int {
    while(start >= 0) {
        yield start;
        start--;
    }
}
```

### Используем в for
```rail
for(let n of countdown(3)) {
    console.log(n);
}
// 3
// 2
// 1
// 0
```

### Используем в while
Для использования в while итератор имеет метод `hasNext`, возвращающий `true`, если ещё остались сохранённые через `yield` значения, которые не были получены.

Так же есть функция `next`, которая вручную двигает итерацию итератора вперёд, к следующему сохранённому значению

```rail
let cd = countdown(3);
while(cd.hasNext()) {
    console.log(cd.next());
}
// 3
// 2
// 1
// 0
```

## Разбираемся, как работает range
Мы немножко потренировались писать свои итераторы, а теперь попробуем разобраться, как работает один из встроенных.

Выглядит он примерно так:
```rail
iterator range(start: int, end: int, step: int): int {
    while(start < end) {
        yield start;
        start += step;
    }
}
```

### Используем в for
```rail
for(let n of range(0, 3, 1)) {
    console.log(n);
}
// 0
// 1
// 2
```
