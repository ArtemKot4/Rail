# Множества
Множество - коллекция, которая содержит уникальные значения.

### Синтаксис
```rail
const set = new Set([1, 2, 3]);
```

### Методы
* `add(value)` - добавляет значение в множество
* `delete(value)` - удаляет значение из множества
* `has(value)` - проверяет, есть ли значение в множестве
* `clear()` - очищает множество
