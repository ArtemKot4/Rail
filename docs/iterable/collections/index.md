# Индексы
Индексы нужны для подписи значений в коллекциях. От коллекции к коллекции они различаются в возвращаемых значениях, однако работа с ними одинаковая:

Представим коллекцию:
```rail
const collection = ...;
```

## Получение значения по индексу
Для получения значения по индексу используется оператор `[]`:
```rail
const value = collection[index];
```

## Установка значения по индексу
Для установки значения по индексу используется оператор `[]`:
```rail
collection[index] = value;
```

## Расширяем возможности оператора индекса
Это применимо не для всех коллекций, а для тех, у которых индекс представлен числами.

Такие коллекции позволяют расширять возможности оператора индекса.

Следующий синтаксис становится нам доступным с кортежами, строками и массивами: `[индекс_от:индекс_до:шаг]`.

Каждое из этих значений можно пропустить, просто ничего не указав. Тогда они станут установленными по умолчанию: для шага значение 1, для индекса начала 0, для индекса конца последний существующий индекс.

Возьмём несколько букв от слова `apple`:
```rail
const letters = "apple"[0:3];
console.log(letters); //"app"

//или

const letters = "apple"[:3];
console.log(letters); //"app"
```

Создадим функцию проверки на палиндром:
```rail
function isPalindrome(word: string): word == word[::-1];
```
Тут мы пропустили шаги от и до, и взяли слово в обратном порядке.
