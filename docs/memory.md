# Память
Rail использует подход `RAII (Resource Acquisition Is Initialization)` вместо сборщика мусора или подсчёта ссылок. 

Данная модель была выбрана с целью избежания задержек или не очень интуитивного поведения.

Все данные стираются после выхода из своей области видимости.

## Разбираем RAII на примере

Создадим область видимости для демонстрации того, где переменная доступна, а где нет.
```rail
{
    let x = 10;
    // x жив
}
// x удален
```

## Копирование данных
По-умолчанию Rail полностью копирует все данные, в том числе примитивы, объекты, экземпляры классов и структур.

```rail
const lang1 = { "name": "Rail" }
const lang2 = lang1;
lang2.name = "Java";

console.log(lang1.name); // Rail
console.log(lang2.name); // Java
```

## Ссылки
Было выбрано решения не добавлять указатели в язык, поскольку по мнению автора функционала ссылок достаточно для управления памятью в процессе написания своих программ.

Ссылки записываются через `&` синтаксис, данный знак пишется только **после** указания типа данных и не применяется вне данного сценария.

```rail
let num = 10;
let arr: int&[] = [num];

let arrLinked: (typeof arr)& = arr;

arrLinked[0] = 5;
console.log(arr); // [5]
console.log(num); // 5
```

Мы создаём число num с значением 10, и создаём массив ссылок на int с названием arr.

Дальше создаём массив `arrLinked`, который берёт тип массива `arr` и указывает, что это ссылка на этот тип через `&` и присваиваем `arr`. Таким образом один массив ссылается на другой.

После чего мы меняем нулевой элемент второго массива, но поскольку это ссылка на первый, в первом тоже меняется. 

При этом хранили мы не просто число, а переменную `num`: поскольку массив типа `int&`, нулевой элемент ссылается на `num` и при изменении его значения изменится и значение `num`.

### А почему не `[&num];`?
Дело в том, что в Rail ссылки передаются автоматически для переменных, если тип данных контейнера предполагает ссылки.

## Случаи без типизации
Случаи, которые часто пишутся без типизации, например такие как циклы, всё же позволяют использовать `&` вне указания типа, и это может быть удобно. Напишем пример с [анонимным итератором](/iterable/iterator.md#анонимные-итераторы):

```rail
console.log(i) for (const i& of range(10)) <void>();
```

## Стек
Это выделенный кусок памяти, который используется для хранения переменных и данных, которые не требуют динамического выделения памяти.

На стеке хранятся данные, которые имеют короткий срок жизни, например переменные внутри функции. Когда функция завершает выполнение, все данные, которые были созданы внутри неё, удаляются из стека.

Важно: По умолчанию все данные (примитивы, объекты на стеке и ссылки) хранятся на нём.

## Куча
Если данные слишком большие или необходимо их хранить в течение долгого времени, то они будут храниться в куче. Куча — это выделенный кусок памяти, который используется для хранения данных, требующих динамического выделения памяти.

Важно: В куче хранятся объекты, созданные через `new`, и динамические структуры (массивы, строки, объекты `{}`), когда они требуют большого объёма памяти.
