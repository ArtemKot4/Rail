## Базовые типы данных
| название | количество байт | назначение
| ----- | ----- | ----- |
| int | 4 | для большинства чисел |
| long | 8 | для огромных чисел |
| float | 4 | для чисел с плавающей точкой |
| double | 8 | для огромных чисел с плавающей точкой |
| boolean | 1 | true или false |
| string\<количество байт> | указанное количество байт | для текста |
string | разное | для текста |
| char | 1 | для символов |

### Числа
Числа у нас записываются несколькими способами:
1. ```rail
   const num: int = 10000;
   ```

2. ```rail
    const num: int = 10_000;
    ```

3. ```rail
    const num: int = 10 000; //да, так тоже можно!
   ```
#### Римские числа (возможно появится в версии 2)
Римские числа - одна из фишек языка Rail, удобная в использовании для работы с историческими данными.

Римские числа могут записываться только с целочисленными типами:
```rail
const century: int = XIX;
```
Они отличаются от обычных чисел лишь способом записи и могут применяться в математических операциях:
```rail
console.log(XIX + 10); //29
console.log(X + X); // 20
```

### Строки
Строки создаются при помощи символа `"` или `'`.
```rail
const str: string = "Hello";
```
#### Сложение с числами
Строки можно складывать с числами, компилятор автоматически преобразует типы.
#### Встраивание значений
В языке Rail взгляд на встраивание значений несколько отличается от JavaScript. В случае JS встраивания мы делали так:
```js
const num = 10;
console.log(`Num is ${num}`); // Num is 10
```
Но поскольку мы не можем создавать строки при помощи ``\, мы складываем их новым способом:
`"строка"значение"строка"` или `"строка"значение`, можно даже `"строка""строка"` как новый способ складывать строки.
```rail
const num: int = 10;
console.log("Num is "num); // Num is 10
```

#### Строки в несколько линий
Раз у нас нет строк при помощи ``, как Rail решает эту проблему? Очень просто!

Вы можете продолжать в несколько линий самые обычные строки, и компилятор сам вставит `\n`
```rail
const text: string = 
    "hello
     rail!
    ";

console.log(text);
//hello
//rail!
```

### unknown 
Это не совсем тип данных, но обозначение удобное. Говорит о том, что тип неизвестен, и очень не желательно к применению, однако иногда удобно.
```rail
const withUnknown = (value: unknown) => console.log("Я не знаю какой это тип");
```

## Union типы
Rail позволяет создавать union типы - перечисление типов. Это работает медленнее, чем строго-выбранный тип, но позволяет придать гибкости в некоторых случаях, подобной TypeScript.

```rail
let x: int | string = 123;
x = "hello";
```

## Произвольные типы

Rail позволяет создавать собственные типы данных.

### Синтаксис:
```rail
type название = тип_данных или выражение;
```

### Пример:
```rail
type universal = int | number;
```

## Объединение типов
Rail позволяет объединять типы способом, похожим на TypeScript объединения при помощи оператора `&`:

```rail
type User = {
    name: string;
    age: number;
}

type Admin = User & {
    isActiveAdmin: boolean;
}

/* теперь Admin это
{
    name: string;
    age: number;
    isActiveAdmin: boolean;
}
*/
```

## null
null - это не совсем тип данных, это скорее его отсутствие. Часто используется в функциях, когда бывают случаи, в которых она не должна вернуть какое-то значение (например мы пытаемся в [map](../iterable/collections/map.md) получить значение при помощи `get(key)`, но значения нет).

### Nullable типы
Rail позволяет создавать типы, которые могут содержать в себе как значение, удовлетворяющее основному типу, так и null значение.

#### Синтаксис:
```rail
тип_данных?
```

#### Пример:
```rail
let apple: int? = null; 
```
Но такие типы не могут быть у константных значений.
