# Лямбда-функции

Лямбда-функции - функции, которые могут быть сохранены в переменные и использованы позже, а так же приниматься в качестве аргументов других функций.

## Синтаксис
Для создания лямбды, мы должны создать подобную конструкцию. Имя не требуется:
```rail
(аргументы) => {
    // тело лямбда-функции
}
```

Напишем лямбду для сложения двух чисел и запишем в переменную:
```rail
const sum = (a: int, b: int) => a + b;
```
Применим:
```rail
console.log(sum(1, 2)); // 3
```

## Типизация
Лямбда-функции могут быть типизированы. Создадим тип, отражающий лямбду для создания коллбека при завершении процедуры:
```rail
type endCallback = () => void;
```

Создадим процедуру, которая принимает лямбду и вызывает ее при завершении процедуры:
```rail
procedure example(callback: endCallback) {
    console.log("Starting example");
    callback();
}

example(() => console.log("Example finished"));
// Starting example
// Example finished
```

Необязательно заключать лямбды в отдельные типы, можно использовать анонимные функции:
```rail
procedure say(message: () => string) {
    console.log("Saying: " + message());
}

say(() => "Hello, world!");
// Saying: Hello, world
```
