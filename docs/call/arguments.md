# Аргументы
Аргументы - это переменные, которые получают свои значения при вызове. Их можно передавать по имени или по порядковому номеру. Записываются в круглых скобках в формате `имя: тип данных`

```rail
//Пример с аргументом a и b
function sum(a: int, b: int): int {
    return a + b;
}

console.log(sum(1, 2)); //значения аргументов a и b при вызове стали значениями 1 и 2
console.log(sum(a=1, b=2)); //вызов с именованными аргументами
```

## Значения по-умолчанию
Аргументы могут содержать значения по-умолчанию: они применятся, если в аргумент при вызове не было передано значение или был передан null.

```rail
function sum(a: int, b: int = 0): int {
    return a + b;
}

console.log(sum(1)); //значения аргументов a и b при вызове стали значениями 1 и 0
```

## Константные аргументы
В языке Rail вы можете создавать константные аргументы: это гарантирует, что их значение вы случайно не измените.

Создадим процедуру с try-catch конструкцией для проверки:
```rail
procedure tryChangeArg(const arg: int = 1) {
    try {
        arg = 2;
    }
    catch {
        console.log("значение не изменилось");
    }
}

tryChangeArg(); //значение не изменилось
```

## Аргументы с передачей по ссылке
Изначально аргументы передаются по значению, и при изменении значения аргумента значение переданной переменной не меняется:
```rail
procedure growValue(value: int) {
    value += 1;
}

let value = 9;
console.log(value); //9
growValue(value);
console.log(value); //9
```
Эта проблема решается при помощи передачи значения по ссылке при помощи оператора `&` после указания типа данных.
```rail
procedure growValue(value: int&) {
    value += 1;
}

let value = 9;
console.log(value); //9
growValue(value);
console.log(value); //10
```

## rest-аргументы
Вы можете создать аргументы, которые будут принимать неограниченное количество значений.

Работа с ними будет происходить как с массивом.
```rail
function sum(...numbers: int[]): int {
    let sum: int = 0;
    for(let num of numbers) {
        sum += num;
    }
    return sum;
}

console.log(sum(10, 5)); //15
console.log(sum(1)); //1
console.log(sum(1, 2, 3, 4, 5)); //15
```

## Инструктированные аргументы
Язык Rail предлагает уникальную возможность создавать перегрузки с аргументами, которые могут содержать в себе условия передачи. 

В случае, если передаваемое значение не будет подходить под условие, программа не скомпилируется.

Для этого мы пишем: `название аргумента: тип данных условие`

```rail
function hasValidAge(age: int >= 18): int {
    return true;
}
```
**Важно**:
1. Вместо названия аргумента в условии мы используем название типа данных, который для аргумента используется. 
2. Ключевых слов по типу if не требуется. 

После компиляции код станет выглядеть так:

```rail
function hasValidAge(age: int): boolean {
    if(!(age >= 18)) {
        throw new CallException("Wrong value for argument age: condition age >= 18 is wrong");
    }
    return true;
}
```
