# Перегрузки
Перегрузки работают для всех вызываемых, кроме лямбд.

Перегрузки нужны для того, чтобы можно было создать несколько вызываемых с одинаковым названием, но разными аргументами.

Это очень полезно в случаях, когда вызываемое в зависимости от типа данных должно делать разные операции

## Пишем свою перегрузку
Создать перегрузку очень просто, нам нужно лишь определить одну и ту же функцию несколько раз, с разным или одинаковым количеством аргументов, но хотя бы один из типов должен отличаться.

```rail
function sum(a: int, b: int): int {
    console.log("int");
    return a + b;
}

function sum(a: double, b: double): double {
    console.log("double");
    return a + b;
}
```

В зависимости от переданных аргументов компилятор решит, какая функция будет вызвана.

Если вы передадите в функцию `sum` два целых числа, то она будет вызвана с первой перегрузкой, а если вы передадите в неё два дробных числа, то она будет вызвана с второй перегрузкой:

```rail
sum(1, 2); //int
sum(1.0, 2.0); //double
```

---
**Важно!**:
1. Если компилятор не сможет определить перегрузку: типы передаваемых значений неизвестны, будут сгенерированы runtime-проверки, поэтому не допускайте передачу unknown аргументов для функций с большим количеством перегрузок.
2. Если вам нужны перегрузки под любые типы, используйте [generic-типы](../type/generics.md#вызываемые-с-generic-типами).
