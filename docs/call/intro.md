## Кратко и о главном
### Функции
[Функции](function.md) - это именованные блоки кода, подписанные собственным названием, которые можно вызывать неограниченное количество раз, передавая в аргументы значения, если того требует перегрузка.

Функции созданы для того, чтобы всегда возвращать значение.

### Процедуры
[Процедуры](procedure.md) - тоже именованные блоки кода, но они не возвращают значения, а только выполняют какие-то действия.

### Лямбда-функции
[Лямбды](lambda.md) - анонимные функции, которые можно вызывать неограниченное количество раз, передавая в аргументы значения, если того требует перегрузка.

Лямбды зачастую нужны для передачи их в функции или процедуры и редко используются как самостоятельные единицы.

## Тело
### Тело функции
Это код внутри `{}`, который и будет выполняться при вызове.

Имеет свою область видимости: переменные, созданные внутри функции, не доступны вне её кода.

Можно переопределять значения из внешних областей видимости

```rail
let word = "hello";

procedure change() {
    word = "world";
}

console.log(word); //hello
change();
console.log(word); //world
```

Функции предполагают в себе return при завершении для возврата значения возвращаемого типа:
```rail
function get(): string {
    return word;
}

console.log(get()); //world
```

`return` завершает выполнение функции и возвращает значение. Иногда используется для раннего выхода если это требуется:

```rail
const validInt: int = 15;

function hasValidInt(arr: int[]): int? {
    for(let num of arr) {
        if(num == validInt) return num;
    }
    return null;
}
```

### Замена тела инструкцией
Это способ создавать функции-предикаты (возвращающие логическое `да` или `нет`, `true` или `false`) с возвращаемым типом с условием.

Синтаксис следующий:
`ключевое_слово название(аргументы): условие;`

Рассмотрим на примере проверки корректного возраста для различных операций:
```rail
// В других языках
function isValidAge(age: number): boolean {
    return age >= 18;
}

// В Rail
function isValidAge(age: int): age >= 18;
```

Однако в случае тернарного оператора можно добиться и более сложного результата.
Сделаем функцию, чтобы получить ответ в виде строки:
```rail
function isValidAge(age: int): age >= 18 ? "да" : "нет";
```
В таком случае перечисление возвращаемых типов будет вычисляться исходя из того, что может вернуть та или иная часть операции, на этапе компиляции.

## Вызов
Создадим функцию для примеров:
```rail
function multiply(...args: int[]): int {
    let result = 1;
    for(let arg of args) {
        result *= arg;
    }
    return result;
}
```

Для вызова нам нужно написать название и передать аргументы.

```rail
название(аргументы);
multiply(1, 2, 3);
```

Если вам нужно передать значения из массива или кортежа фиксированного размера (если аргумент не является rest), вы можете воспользоваться spread оператором

```rail
let arr = [1, 2, 3];
console.log(multiply(...arr)); // 6
```

Есть ещё один способ вызова, иногда он более удобный, но нужно аккуратно использовать, чтобы код оставался читаемым:
```rail
console.log "hello rail!";
```
При таком вызове функций в аргументы будет собрано всё до точки с запятой

## Рекурсия
Рекурсия - вызов функции внутри самой себя.

```rail
// Важно: глубокая рекурсия может вызвать переполнение стека
function factorial(n: int): int {
    if(n == 0) return 1;
    return n * factorial(n - 1);
}
```

## Замыкание
Замыкание - функция, которая сохраняет значения переменных, которые были вычислены во время выполнения функции и возвращает функцию.

```rail
function counter() {
    let count = 0;
    return function() {
        count++;
        return count;
    }
}

let count = counter();
console.log(count()); // 1
console.log(count()); // 2
console.log(count()); // 3
```
