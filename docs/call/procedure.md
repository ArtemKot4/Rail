# Процедуры
Процедуры - именованные блоки кода, которые выполняют действия, но не возвращают значения. Вдохновлены Pascal, добавлены для того, чтобы явно отличать функции (в контексте других языков, таких как Java, C++, C#, TypeScript), которые нужны только для возврата значений от функций, которые нужны только для выполнения действий.

Процедуры нужны только для выполнения команд.

## Синтаксис
Чтобы создать процедуру, нам нужно применить ключевое слово `procedure` и название процедуры. Затем мы можем указать аргументы, которые будут переданы в процедуру.
```rail
procedure название(аргументы: типы_данных) {
    // тело процедуры
}

// если нет аргументов
procedure название {
    // тело процедуры
}
```

## Примеры
```rail
procedure sayHello(name: string) {
    console.log("Hello, " + name);
}

procedure main {
    sayHello("John");
}
```
