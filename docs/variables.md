# Переменные
Переменные в языке Rail нужны для хранения значений в именованных ячейках


## Объявление:
Есть два способа создать переменную:

1. Неизменяемый (константа)
    ```rail 
    const название: тип_данных = значение;
    ```
2. Изменяемый
    ```rail
    let название: тип_данных = значение;
    ```

**Важно**:

В языке Rail никогда нельзя было создавать переменную при помощи ключевого слова `var`, и в будущем это не появится. Это было сделано специально, поскольку он утратил своё значение.

Поэтому вы можете сделать так :)
```rail
const var = "let";
print(var); //let
```

Тип данных указывать необязательно, если сразу указано значение:

```rail
let apple = "Яблоко";
```

Если вам нужно создать переменную, но дать ей значение позже, вы можете написать так:

```rail
let apple: int?
```

## Изменение
Для изменения значения переменной вы можете использовать оператор присваивания:

```rail
let apple = "яблоко";
apple = "апельсин";
```

Вы можете делать это для null-значений:

```rail
let apple: int? = null;
apple ??= 1;
```

Тогда значение изменится только при условии того, что оно было null.

## Копирование значений
Для того, чтобы скопировать значение, вам нужно присвоить второй переменной значение первой.

```rail
let animal = "кот";
let cat = animal;

console.log(cat); //кот
console.log(animal); //кот

cat = "кошка";
console.log(cat); //кошка
console.log(animal); //кот
```

## Передача по ссылке
Бывают случаи, в которых вам нужно получить значение другой переменной, при этом имея доступ к нему в памяти: это позволяет через изменение одной переменной менять значение другой.

Для этого используются ссылки. Они ссылаются на значения, которые берут и возвращают их с возможностью изменения. Не работает для констант.

Чтобы взять ссылку на переменную при типизации, используйте оператор `&` после обозначения типа:

```rail
let apple: string = "яблоко";
let banana: string& = apple;
console.log(banana); //яблоко
banana = "банан";
console.log(apple); //банан
```

В таком случае Rail сам передаст ссылку. Этот способ самый предпочтительный.

Если по какой-то причине мы не можем указать тип данных или мы создаём переменные в цикле, мы можем использовать оператор `&` после названия.

```rail
for(const char of apple&.split()); {
    console.log(char);
}

// б
// а
// н
// а
// н
```
Благодаря этому подходу мы не копируем `apple`.
