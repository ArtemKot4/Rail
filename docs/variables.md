# Переменные
Переменные в языке Rail нужны для хранения значений в именованных ячейках


## Объявление:
Есть два способа создать переменную:

1. Неизменяемый (константа)
    ```rail 
    const название: тип_данных = значение;
    ```
2. Изменяемый
    ```rail
    // первый способ (предпочтительнее)
    let название: тип_данных = значение;
    // второй способ
    название: тип_данных = значение;
    ```

**Важно**:

В языке Rail никогда нельзя было создавать переменную при помощи ключевого слова `var`, и в будущем это не появится. Это было сделано специально, поскольку он утратил своё значение.

Поэтому вы можете сделать так :)
```rail
const var = "let";
print(var); //let
```

Тип данных указывать необязательно, если сразу указано значение:

```rail
let apple = "Яблоко";
```

Если вам нужно создать переменную, но дать ей значение позже, вы можете написать так:

```rail
let apple: int?
```

## Изменение
Для изменения значения переменной вы можете использовать оператор присваивания:

```rail
let apple = "яблоко";
apple = "апельсин";
```

Вы можете делать это для null-значений:

```rail
let apple: int? = null;
apple ??= 1;
```

Тогда значение изменится только при условии того, что оно было null.
