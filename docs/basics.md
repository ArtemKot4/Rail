# Основы
Rail - статически типизированный, вдохновлённый величием CoffeeScript, TypeScript, Python, Java компилируемый язык программирования, который позволяет писать программы со скоростью, подобной C++, но при этом с простым синтаксисом.

## Комментарии
Комментарии в языке Rail создаются точно так же, как и в JavaScript:
```rail
//однострочный комментарий

/*
многострочный
комментарий
*/
```

---

Особенности:
- Язык написан на основе LLVM, что позволяет ему достигать скорости, подобной C++
- Язык компилируется, что позволяет исключить многие ошибки на этапе компиляции
- Синтаксис языка похож на TypeScript, CoffeeScript, Java и Python, что позволяет легко перейти на него
- Удобная система потоков, позволяющая просто и быстро создавать системы, работающие под большой нагрузкой

---

Важно знать:
- Каждый файл в Rail должен иметь расширение .rail
- Коду не требуется главная функция чтобы выполниться, можете писать в стиле JavaScript кода
- Практически каждое выражение требует точки с запятой в конце
