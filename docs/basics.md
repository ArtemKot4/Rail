# Основы
Rail - статически типизированный, вдохновлённый CoffeeScript, TypeScript, Python, Java компилируемый язык программирования, который позволяет писать программы со скоростью, подобной C++, но при этом с простым синтаксисом.

Данный язык имеет одну из самых программируемых систем типизации, что позволяет только на одной основе типов совершать действия над кодом.

Важное пояснение: практически каждая вещь, представленная в документации, находится на стадии реализации или проектирования, поэтому стоит относиться к этому как к спецификации языка, которая будет становиться всё актуальнее с годами.

## Комментарии
Комментарии в языке Rail создаются точно так же, как и в JavaScript:
```rail
//однострочный комментарий

/*
многострочный
комментарий
*/
```

---

Особенности:
- Язык написан на основе LLVM, что позволяет ему достигать скорости, подобной C++
- Язык компилируется, что позволяет исключить многие ошибки на этапе компиляции
- Синтаксис языка похож на TypeScript, CoffeeScript, Java и Python, что позволяет легко перейти на него
- Удобная система потоков, позволяющая просто и быстро создавать системы, работающие под большой нагрузкой

---

Важно знать:
- Каждый файл в Rail должен иметь расширение .rail
- Коду не требуется главная функция чтобы выполниться, можете писать в стиле JavaScript кода
- Практически каждое выражение требует точки с запятой в конце
