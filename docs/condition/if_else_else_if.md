# Если, иначе, иначе если

Привет читатель! В этой статье мы рассмотрим следующие способы создавать логику в коде на Rail.

## if - если

Этот оператор позволяет создавать любые проверки.
Несколько способов записи:

1. ```rail
   if(условие) следствие;
   ```

2. ```
   if(условие) {
       следствие
   }
   ```

3. ```rail
   if условие {
       следствие
   }
   ```
   
   Этот способ нежелателен, но допустим. Сделан для удобного перехода с таких языков, как golang.

4. ```rail
    следствие if условие;
   
    //пример:
    for(let i = 0; i < 10; i++) {
        continue if i % 2 == 0; //пропустим все чётные числа
        console.log(i);
    }
   ```
   
   ## else - иначе
   
   Это следствие невыполнения if: это тот код, который выполнится именно в случае, когда условия внутри if не соблюдены.
   
   ```rail
   if(условие) {
    следствие
   } else {
    иначе следствие
   }
   ```
   
   ## else if - иначе если
   
   Если нужно добавить дополнительные условия, можно использовать else if.
   
   ```rail
   if(условие) {
    следствие
   } else if(условие2) {
    иначе следствие2
   } else {
    иначе следствие3
   }
   ```
