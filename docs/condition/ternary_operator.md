# Тернарный оператор
Тернарный оператор - компактный if else.

В языке Rail он слегка отличается от JavaScript.

## Синтаксис
Тернарный оператор используется данным образом: `условие ? следствие : иначе`

По сути это то же самое, что и:
```rail
if(условие) {
    следствие
} else {
    иначе
}
```
Но в компактной форме.

Рассмотрим на следующем примере: 
У нас есть список оценок, и мы хотим узнать, подходит ли у нас средний балл под минимальный допустимый.

```rail
const marks: int[] = [5, 4, 3, 2, 2, 4]; // список оценок
```
Попробуем сделать это при помощи if else:
```rail
let valid: string?; //подходит ли, запишем в виде "да" или "нет"

const sum = Math.sum(marks); //получим сумму оценок

const length = marks.length; //получим количество оценок

const average: float = sum / length; //получим средний балл

if(average >= 3) {
    valid = "да";
} else {
    valid = "нет";
}
```

Попробуем сделать то же самое при помощи тернарного оператора:
```rail
const valid = average >= 3 ? "да" : "нет";
```

Это работает не только с переменными, это может передаваться сразу в качестве значения. Давайте сделаем [функцию](../call/function.md), которая [вернёт "да" или "нет" в зависимости от того, подходит ли средний балл под минимальный допустимый](../call/intro.md#замена-тела-инструкцией).

```rail
function isValid(marks: int[]): Math.sum(marks) / marks.length >= 3 ? "да" : "нет";
```

Попробуем использовать функцию:
```rail
console.log(isValid(marks))
```
