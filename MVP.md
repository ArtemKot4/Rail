# Первый компилятор
Первый компилятор нужен для того, чтобы основной компилятор мог быть скомпилирован на самом Rail, а потому в нём не планируется огромное количество возможностей, которые будут реализованы в основном компиляторе.

Этот компилятор можно считать неким прототипом, который нужен для того чтобы компилятор мог быть написан на самом языке.

## Сводная таблица

| Что будет | В чём важность |
| --- | --- |
| Переменные | Необходимая вещь для написания практически любого кода |
| Функции и процедуры | Переиспользуемость |
| Типизация: указание типа данных, так же пересечение и слияние типов, типизация лямбд, объектов, массивов, указание ссылки и nullable | Понадобится для написания второго компилятора с предсказуемым поведением |
| Циклы | Для написания всех видов анализа |
| Массивы, объекты, кортежи | Хранение данных |
| Условные операторы | Описание поведения |
| Очень простая система импортов | Для подключения разных файлов |
